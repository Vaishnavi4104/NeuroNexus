# Registration Landing Page

A modern, responsive registration form inspired by Google Forms. Built using only **HTML** and **CSS**.

## Features
- Clean, Google Forms-inspired design
- Responsive layout for desktop and mobile
- Collects:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (dropdown)
  - Gender (radio buttons)
- Required field indicators
- Blue theme (customizable)
- Minimal, accessible markup

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Vaishnavi4104/NeuroNexus.git
   cd your-repo
   ```
2. **Open `index.html` in your browser.**

## Deployment

### Deploy on Vercel
1. Push your project to GitHub.
2. Go to [Vercel](https://vercel.com/) and sign in with GitHub.
3. Click **"Add New Project"** and import your repository.
4. Use the default settings for a static site.
5. Click **"Deploy"** and get your live URL!

## Customization
- Change the theme color in `style.css` by editing the `background-color` and accent color variables.
